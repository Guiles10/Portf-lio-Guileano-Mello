# Portfólio Guileano Mello

Este é um projeto de portfólio premium desenvolvido com [Next.js](https://nextjs.org) e focado em alta performance e UI/UX sofisticada.

## Sobre o Projeto
O portfólio utiliza um sistema unificado de "Catalyst Core" para visualizar sinergia tecnológica, além de componentes otimizados para total responsividade (320px a 1440px).

## Getting Started

Primeiro, rode o servidor de desenvolvimento:

```bash
npm run dev
# ou
yarn dev
# ou
pnpm dev
# ou
bun dev
```

Abra [http://localhost:3000](http://localhost:3000) no seu navegador para ver o resultado.
